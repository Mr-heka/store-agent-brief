# Store Agent Brief

Writes a developer brief for putting Anthropic's Commerce Agents blueprint on a real store: what to connect, what to lock down, and who approves changes.

**Who it is for:** Store owners and operators who want to brief a developer properly.

**What you need:** Claude Code or Codex and what you know about your store systems. A developer does the build.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
